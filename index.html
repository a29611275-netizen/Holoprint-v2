Documentation

How to use HoloPrint+ packs in Minecraft Bedrock

How it Works

  1. Export a .mcstructure using Structure Block in Creative (Windows recommended, or use world extract tools on mobile).
  2. Upload the file(s) here, set name, offsets, rotation.
  3. Download the generated .mcpack and import it into Minecraft.
  4. Create/open a world, enable the Behavior Pack + Beta APIs experiment.
  5. In Creative, place an Armor Stand.
  6. Hold a Netherite Ingot and interact (right-click / long-press) the Armor Stand.
  7. The structure places as real blocks at the Armor Stand position + your offsets & rotation.

Requirements

  • Minecraft Bedrock 1.21+ recommended (Script API StructureManager)
  • Beta APIs experiment must be enabled in the world
  • Creative mode recommended for testing (works in Survival too if you have the items)

Useful Commands

/give @s structure_block
/give @s netherite_ingot
/summon armor_stand ~ ~ ~

Limitations

  • Structure size is limited by Minecraft (typically ~64 blocks in any direction for reliable placement).
  • Android Structure Block Export button is hidden in recent versions — save to world then extract .mcstructure using external tools or PC.
  • Requires Beta APIs experiment (disables achievements in that world).
  • Only places the structure selected in the pack generator. Multiple structures can be included but one primary is used for the Armor Stand trigger.

About HoloPrint+

HoloPrint+ is inspired by the original HoloPrint project (which creates hologram resource packs).

This version focuses on actual block placement using the official Minecraft Bedrock Script API (world.structureManager.place).

Built as a pure client-side web app — HTML, CSS, JavaScript + JSZip. No servers, no accounts, no tracking of your files.

Perfect for creators who want to share builds that players can spawn with one simple interaction.
